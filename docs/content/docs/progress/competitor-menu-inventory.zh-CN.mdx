# 竞品菜单与功能全量清单

这份文档解决一个问题：**别人到底有哪些菜单、每个菜单下面有什么**，以及**我们逐项对照是什么状态**。

## 一、先说清楚边界

你要的是「一模一样」。有两件事必须先讲明白，否则后面会一直对不上：

1. **菜单结构、功能入口、交互流程可以对齐**——这些是前端能做的，我们会逐项复刻。
2. **菜单背后的东西不可能一模一样**：会员计费、云账号与团队协作、模型生态（别人是自家模型 + 合作方）、社区作品供给、3D 素材库、正版字体/音乐版权。这些要么需要后端与运营，要么需要商业授权。**代码写得出来，资源变不出来。**

所以下面的清单分成三类标记：`可复刻`（前端即可）、`需后端`（要服务端与账号体系）、`需资源`（要内容/版权/算力）。

3. 导航补齐：把「生图工作台 / 视频创作台」提升为一级菜单，与竞品的「视频生成 / 图片生成」对齐 ✅

5. 文本/提示词版本快照
6. 成片预览（按导出顺序连播，先确认节奏）✅
7. ComfyUI 工作流接入 ✅（官方插件 `comfyui-workflow`）

**第二批（需要一个上游能力）**
6. 字幕生成（接 ASR 接口）
7. 全景图查看
8. 模型生态页

**第三批（需后端 / 需资源，先搭结构后填内容）**
9. 社区精选（先做本地「我的模板/我的作品」画廊，再考虑云端）
10. 学院（内置图文教程页）
11. 会员 / 积分 / 团队（等有云端账号体系再做）

## 六、我不建议照抄的部分

- **完整非编时间线**：MiniMax 的时间线是给「不想离开这个软件」的人做的。我们的判断是「生成在画布、剪辑在剪映」，抄了会拖慢主线。
- **3D 预演**：素材库 + 机位系统 + 渲染，投入极大，且只在特定类型片子里有用。
- **团队与积分体系**：本地优先架构下没有账号就没有团队，先做导出/导入覆盖协作。
