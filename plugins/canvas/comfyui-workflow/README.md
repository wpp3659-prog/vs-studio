# ComfyUI 工作流节点

把本机(或局域网)ComfyUI 的 **API 格式工作流**接进画布:选提示词节点、输入提示词、运行,结果直接回到画布。

## 用法

1. 在 ComfyUI 里调好工作流,菜单 **Workflow → Export (API)** / 「保存(API格式)」,得到一份 JSON。
2. 画布添加「ComfyUI 工作流」节点 → 点 **设置** → 粘贴 JSON。
3. 节点会自动列出可写提示词的节点(带 `text` 输入的,通常是 CLIPTextEncode),选好正向提示词那个。
4. 输入提示词 → **▶ 运行工作流** → 结果出现在节点里,点 **铺到画布** 变成图片节点。

## 关键点

- **地址**默认 `http://127.0.0.1:8188`。ComfyUI 默认不返回 CORS 头,浏览器直连会被拦,所以默认走画布自带的本地代理 `127.0.0.1:23210`(由 `一键启动.bat` 启动)。ComfyUI 加了 `--enable-cors-header` 时可以关掉代理。
- **工作流必须是 API 格式**。界面格式(顶层是 `nodes` / `links` 数组)会被直接拒绝,并提示重新导出。
- **上游图片**勾「用上游图片」后,会把上游图片节点的图上传到 ComfyUI 的 `input/`,并写进你选的「加载图像」节点,用于图生图 / 重绘。
- 轮询 `/history` 间隔 1.5 秒,上限 10 分钟;超时只报错,**不会自动重发**(避免重复占用显卡)。
- 工作流里必须有「保存图像」节点,否则执行完成也没有输出。

## 接口

| 用途 | 接口 |
| --- | --- |
| 连接测试 | `GET /system_stats` |
| 提交任务 | `POST /prompt` |
| 查结果 | `GET /history/{prompt_id}` |
| 取图 | `GET /view?filename=&subfolder=&type=` |
| 上传输入图 | `POST /upload/image` |
